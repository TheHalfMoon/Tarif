# Tarif

**Open-source authority infrastructure for AI agents.**

Tarif is being founded as a local-first, self-hostable authority runtime for controlling what AI agents may do across tool and service boundaries.

> The model may propose. Deterministic policy authorizes. Runtime enforcement proves what happened.

</div>

---

## Project status

Tarif is in its founding research and architecture phase. No production-security claim is made yet.

The initial program will be shaped using bounded specifications, explicit trust boundaries, risk-scaled verification, and evidence-backed claims before implementation authority expands.

## Founding direction

Tarif is intended to make secure agent execution free and self-hostable, while composing open standards instead of inventing proprietary identity, authorization, or policy protocols where adequate standards already exist.

Initial focus areas include:

- deterministic action authorization;
- MCP mediation;
- exact-parameter and stale-state enforcement;
- human approval binding;
- credential isolation;
- explainable authorization evidence;
- honest enforcement-coverage inspection;
- standards-native interoperability.

Future areas such as A2A, HTTP mediation, delegation graphs, credential brokering, and information-flow controls are research directions, not current implementation authority.
