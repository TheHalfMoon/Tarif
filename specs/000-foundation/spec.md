# Specification 000 — Project Foundation & Constitution

Status: `ACTIVE_FOUNDING`
Risk: `R1` for documentation/governance mutation; security doctrine itself requires substantive review because it constrains later R3 work.

## Outcome

Tarif has one coherent, repository-canonical foundation that defines the product category, open-source doctrine, trust principles, source strategy, execution method, and dependency-ordered v0.1 program without authorizing runtime implementation.

## Scope in

- README founding position and explicit pre-production status;
- Apache-2.0 license;
- project constitution;
- repository engineering rules;
- product thesis;
- founding trust-model draft;
- standards/source/competitor/threat research maps;
- evidence-shaped roadmap;
- execution master plan;
- current-program state;
- Specification 000 plan/tasks.

## Scope out

- Rust workspace or production code;
- MCP implementation;
- policy/canonicalization implementation;
- runtime credentials;
- agent integrations;
- CI architecture beyond what is strictly needed to verify this documentation-only foundation;
- release publication;
- superiority/replacement benchmarks;
- proprietary protocol/token/policy/crypto design.

## Acceptance

1. Repository documents agree that Tarif is an open-source authority runtime, not a general IdP/secrets manager/agent framework.
2. Constitution includes deterministic authority, default deny, honest mediation, credentials outside model authority, standards-before-invention, security-not-paywall, evidence-before-claims, risk-scaled rigor, and roadmap-not-authority rules.
3. Source map distinguishes stable standards from unstable drafts and competitors from dependencies.
4. Initial program is dependency-ordered 000→009 and only 000 is active.
5. README clearly states that no production-security claim exists yet.
6. Apache-2.0 license is present and consistent with the open-source doctrine.
7. No runtime implementation is introduced by this specification.
8. Exact founding diff receives the verification/review evidence required by the live repository state before merge.

## Claim boundary after completion

Allowed:

> Tarif is an Apache-2.0 open-source project being developed as authority infrastructure for AI agents under an evidence-shaped, security-first program.

Not allowed:

- "Tarif secures AI agents."
- "Tarif prevents prompt injection."
- "Tarif replaces Descope/Aembit/Permit/Auth0/Okta/Entra."
- "Tarif is production-ready."
- any performance or security-superiority claim.

## Recovery

Because this specification is documentation/governance only, recovery is reverting the exact founding commit/merge if the canonical documents are found inconsistent or materially incorrect. Runtime behavior does not yet depend on these files.
